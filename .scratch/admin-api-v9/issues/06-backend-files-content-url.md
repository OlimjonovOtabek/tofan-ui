# 06 - Backend so'rovi: GET /files da contentUrl

**What to build:** Backend jamoasi admin media sahifasi uchun nima kerakligini aniq biladi.
`GET /files` (va `GET /files/{id}`) javobidagi har faylda `contentUrl` bo'lishi kerak: video uchun imzoli havola, rasm uchun oddiy havola.
Shunda mashqqa bog'lanmagan video ham himoya yoqilgach ko'riladi va yuklab olinadi.

**Blocked by:** None - can start immediately

**Status:** ready-for-agent
